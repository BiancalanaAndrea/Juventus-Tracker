JUVENTUS TRACKER V1

Questo archivio contiene la prima base funzionante del progetto.

Per partire:
1) installa Node.js
2) apri questa cartella nel terminale
3) npm install
4) npm run dev
5) vai su http://localhost:3000

Per la sincronizzazione:
- crea un progetto Supabase
- copia .env.example in .env.local
- inserisci URL + publishable key
- esegui supabase/schema.sql nel SQL Editor

Per ora l'interfaccia usa dati demo. Il prossimo passaggio è collegare Supabase alle pagine e poi il provider calcistico live.
